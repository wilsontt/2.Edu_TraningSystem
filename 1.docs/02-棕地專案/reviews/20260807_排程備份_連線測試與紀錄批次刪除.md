# 排程備份：連線測試與紀錄批次刪除

**日期**：2026-08-07  
**範圍**：系統管理 → 排程備份設定

## 1. 目的

補強排程備份設定頁：設定後可驗證 NAS 連線；備份紀錄支援分頁與勾選批次刪除（可選是否同步刪 NAS ZIP）。

## 2. 範圍

| 項目 | 說明 |
|------|------|
| 含 | `POST /api/admin/backup/test-connection`；`DELETE /api/admin/backup/records/bulk-delete`（`delete_nas_files`）；前端連線測試／勾選／批次刪除；備份紀錄表格含「項次」並使用與人員管理相同的 `common/Pagination`（每頁顯示／共 N 筆／第 x 頁） |
| 不含 | UI 一鍵還原／匯入（仍依 NAS PLAN SOP／維運腳本） |

## 3. API

### 連線測試

`POST /api/admin/backup/test-connection`  
Body（皆選填）：`destination`、`backup_nas_username`、`backup_nas_password`  
- 密碼留空 → 使用已存加密密碼  
- 回傳 `{ ok, message }`（HTTP 200；失敗亦以 `ok: false` 表達）

### 批次刪除

`DELETE /api/admin/backup/records/bulk-delete`  
Body：`{ record_ids: number[], delete_nas_files?: boolean }`  
- `delete_nas_files=false`：僅刪 `backup_records`  
- `true`：先連 NAS；連線失敗 → **503** 且不刪 DB；檔案不存在視為可忽略；其餘刪檔失敗記入 `nas_failed` 後仍刪 DB 紀錄  
- 回傳：`deleted_count`、`missing_ids`、`nas_deleted_count`、`nas_failed`

權限：`menu:admin:backup`
