# 訓練計畫免考三層級 — 實作計劃 (PLAN)

**文件類型**：棕地實作計劃  
**建立日期**：2026-07-28  
**狀態**：✅ **已實作**（待人工 UI 驗收；部署須執行 migration）  
**技術設計**：[20260728_訓練計畫免考三層級_技術設計.md](20260728_訓練計畫免考三層級_技術設計.md)  
**相關**：[20260723_超管考試中心試考模式_PLAN.md](20260723_超管考試中心試考模式_PLAN.md)（試考模式另案；本 PLAN 不實作試考）

> **背景**：訓練計畫受課對象僅有「單位 ∪ 個人」。產品需要另以**角色／單位／個人**設定免考；受課 UI 不混入免考；超管預設且鎖定免考；**僅超管免報到**，其餘免考者仍須報到。

---

## 1. 目的

1. 新增計畫層級免考設定（角色／單位／個人），與 `target_*` 分離。
2. 考試中心與成績／待考口徑改吃「實際需考」。
3. 報到應到口徑：含一般免考者、排除預設超管。
4. 前端：開課單位旁「免考設定」子 modal＋主畫面摘要。

### 2.3 審核決策（已定案）

| # | 決策 |
|---|------|
| Q1 | 免考＝角色 ∪ 單位 ∪ 個人（OR）；排除優先於受課 |
| Q2 | `target_*` 與 `exam_exempt_*` 分開；受課 UI 不顯示／不扣除免考 |
| Q3 | UI：開課單位旁「免考設定」→ 子 modal；主 modal 僅摘要 |
| Q4 | 超管角色預設寫入免考且**不可取消**（後端強制） |
| Q5 | **僅預設超管免報到**；其餘免考者**要報到**、計入應到 |
| Q6 | `my_exams`：**不**把免考計畫列為可開考任務（極簡） |
| Q7 | 與試考 PLAN：本波不實作試考；helper 以角色名判斷超管，不依賴 `is_trainee`  alone |
