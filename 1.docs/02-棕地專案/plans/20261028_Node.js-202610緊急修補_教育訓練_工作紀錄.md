## 4. 名詞解釋

| 名詞 | 說明 |
|------|------|
| 修補版 | Node 22.x ≥ `22.23.4`；24.x ≥ `24.22.1` |
| 版本鎖定 | 以 `.nvmrc` 與 `package.json` 的 `engines` 固定 Node 版本要求 |

| builder | 多階段建置中僅用於編譯前端的 Node 階段；最終 runtime 為 `nginx:alpine`，不含 Node |

### 5.3 決策紀錄

`0.shared-ui` 的 `engines` 為 `>=24.22.1`。builder 若停留在 22.23.4，每次 `npm ci` 都會出現 `EBADENGINE` 警告，故由專案負責人決定將會編譯 `0.shared-ui` 的前端 builder 一併升至 `24.22.1`。`engines >=22.23.4` 仍保留，作為最低允許版本。
