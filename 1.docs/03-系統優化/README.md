## 一、目的

收錄**非當下迭代必做**、但已從實務維運或架構討論確認的優化／技術債議題，供日後排程處理。  
與 `02-棕地專案/` 差異：棕地為**已開案或進行中的功能增強**；本目錄為**待排程的優化 backlog**（尚未立正式 PLAN／TASKS 前可先記於此）。

---

## 二、使用方式

1. 新議題：新增 `YYYYMMDD_<簡短主題>.md`（建議含目的／範圍／現況／待辦）。
2. 開工時：可移轉為 `02-棕地專案/plans/` 正式 PLAN，並在本 README 將狀態改為「已開案」並附連結。
3. 結案時：標記完成日期，或移入棕地 `plans/已完成/` 後於此註記。
